# E-Commerce Wireframe Templates

This directory contains SVG wireframe templates for common e-commerce website pages. These templates serve as references for generating new wireframes with similar layouts and components.

## Available Templates

### 1. Product Listing Page (`product-listing.svg`)
- Header with navigation and search
- Product grid layout (4 products per row)
- Product cards with images, titles, prices, and "Add to Cart" buttons
- Pagination controls
- Responsive grid design

### 3. Shopping Cart (`shopping-cart.svg`)
- Cart items list with product images and details
- Quantity controls and remove options
- Order summary sidebar with subtotal, shipping, tax, and total
- "Proceed to Checkout" and "Continue Shopping" buttons
- Item count display in header

### 4. Checkout Page (`checkout.svg`)
- Multi-step checkout process
- Shipping information form
- Payment information form
- Order summary with itemized breakdown
- Secure checkout button
- Form validation indicators

### 5. User Profile/Account Page (`user-profile.svg`)
- Sidebar navigation for account sections
- Personal information form
- Account preferences (notifications, newsletter)
- Recent orders summary
- Profile picture placeholder

## Usage

These templates can be used as:
- Reference designs for new wireframe generation
- Starting points for custom e-commerce wireframes
- Examples of common UI patterns and layouts

## Customization

Each template includes:
- Consistent color scheme (blues, greens, grays)
- Standard e-commerce UI components
- Responsive layout considerations
- Accessibility-friendly design elements

## File Format

All templates are in SVG format for:
- Scalable vector graphics
- Easy modification and customization
- Web-ready format
- Small file sizes
